## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/tmanju01/my-portfolio.git
```

### Go to the project folder

```bash
cd my-portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
